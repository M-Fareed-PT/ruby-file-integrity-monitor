# ruby-file-integrity-monitor
# 🛡️ Ruby File Integrity Monitoring System  
A simple but powerful Ruby tool that monitors files, generates hashes, detects modifications, and alerts the user of unauthorized changes. This mimics real FIM tools like Tripwire or OSSEC.

---

## 🚀 Features
✔ Tracks file changes using SHA256  
✔ Detects creation, modification, and deletion  
✔ Real-time monitoring mode  
✔ Custom watchlist support  
✔ Simple CLI reporting  

---

## 🧠 Skills Demonstrated
- Ruby scripting  
- Hashing (SHA256)  
- File system monitoring  
- Logging & reporting  
- Security automation  
- Integrity verification
